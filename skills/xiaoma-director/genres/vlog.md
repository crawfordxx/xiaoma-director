# Vlog

## 判定信号与相邻片种

- 信号：vlog、旅行记录、日常记录、一天的生活、跟我一起、周末去哪、独居、「一个人去……」
- 和**纪录片**的区别：Vlog 的拍摄者就是主角，第一人称，对着镜头说「我」，可以重说一段对镜口述，可以自己架机位走进画面；纪录片的拍摄者隐身，不摆拍
- 和**达人口播**的区别：口播是一个人对镜讲一件事、导向购买，15–60 秒竖屏；Vlog 是生活流，按时间线走，以分钟计，广告植入只是其中一段
- 和**文旅宣传片**的区别：文旅片以地方为主角、第三人称、追求壮阔；Vlog 以「我的这一天」为主角，地方是我看到的样子，再好看的风景也要落到我的反应上

## 默认规格

| 项 | 横屏长 vlog（B 站、YouTube） | 竖屏短 vlog（抖音、小红书） |
|---|---|---|
| 时长 | 5–15min | 1–3min |
| 每分钟镜数 | 12–25 | 20–35 |
| A-roll 占比 | 40–50% | 30–40% |
| A-roll 镜长 | 4–15s（跳切之后） | 2–6s |
| B-roll 镜长 | 1.5–4s；定点走入走出 6–10s；情绪段长镜 10–30s | 1–2.5s |
| 画幅 | 16:9 | 9:16 |

超过 3 分钟的 vlog 先做开头 60 秒，`scope` 设为 `segment`。

## 结构模板

真实时间线 + 一个「今天的问题」（6 分钟为例的占比）：

| 节拍 | 占比 | 做什么 |
|---|---|---|
| 钩子 | ~5%（前 10–15 秒） | 当天最好的画面闪前 + 一句话交代今天要干什么 |
| 出发 | ~10% | 起床、出门，交代时间和天气，抛出今天的问题（能不能看到、能不能到、能不能成） |
| 时间线段落 ×3–4 | ~60% | 每段：到达的 B-roll → A-roll 说感受或信息 → 细节 B-roll → 一个小意外或小发现 |
| 高光 | ~15% | 问题的答案：看到了 / 没看到。音乐退下，环境声上来，允许长镜 |
| 收尾 | ~10% | 回住处或入夜，对镜一两句总结，下期预告或互动 |

「今天的问题」是 vlog 不变成流水账的关键：五点起床去看日出，问题就是「今天有没有雾」，整条片子都在等这个答案。

## 第一人称、真实时间线与 A-roll / B-roll

**1. A-roll 是「我在说」，B-roll 是「我在看、我在做」**

| 类型 | 机位 | 内容 | 分镜里写什么 |
|---|---|---|---|
| A-roll · 自拍对镜 | 手持或自拍杆，广角，一臂距离 | 当下的感受、计划、信息 | 要说的 2–3 个要点和预期的那一句，不写逐字稿 |
| A-roll · 三脚架对镜 | 定点，中近景到中景 | 坐下来的讲述、总结 | 同上，加上背景要拍到什么 |
| B-roll · 主观 | 手持，或胸前、头戴运动相机 | 我看到的：推门、走路、手里的东西 | 第一个动作和看到的东西 |
| B-roll · 三脚架定点 | 定点，人走入走出 | 我在环境里的样子 | 机位位置、走位路线 |
| B-roll · 空镜 / 延时 | 三脚架 | 天色、风景、时间流逝 | 拍多久、压成几秒 |

**2. 真实时间线**：按当天的顺序剪，可以压缩，不可以颠倒。开头闪前是唯一例外，要用字幕或画面标明时间已经跳回去（冰花、天黑、时间字幕）。时间靠画面交代：天色、时钟、时间字幕、餐点、体力。

**3. A-roll 写要点不写台词**：现场用自己的话说，说错就重来一句，剪辑跳切掉停顿和口误；`dialogue` 里写预期的那一句，用来估时长。

**4. 一个人能拍**：分镜里每个机位都要是拍摄者自己能完成的。三脚架定点走入走出、手机自拍、运动相机主观，是一个人的三件套；跟拍、环绕、远处跟随需要第二个人，要在 `notes` 写明。

**5. 每镜标确定性**：`notes` 开头写「可预期」（日程里确定的：起床、出门、到达）或「需捕捉」（天气、遇到的人、意外），需捕捉的写清楚拍不到时用什么顶。

- ❌ 全程举着手机说，五分钟只有一张大脸
- ❌ 全是航拍和风景空镜，看不出是谁去的，变成文旅片
- ✅ 每段 A-roll 后面接 2–4 个 B-roll，嘴上说到「冷」，画面就切到窗上的冰花

## 节奏基准

- 开头 15 秒内交代今天去哪、干什么
- A-roll 跳切掉停顿；单段 A-roll 超过 20 秒就用 B-roll 盖一下
- 每 30–60 秒一组 B-roll 蒙太奇（3–6 镜，卡 BGM）
- 高光处音乐退下、环境声上来，允许 10–30 秒的长镜：一个人坐着看风景，什么都不说
- 出彩镜头两成左右：闪前、定点走入走出、长镜留白、匹配剪辑

## 招牌镜头

- **自拍对镜**：广角，一臂距离，人在画面中间偏下，背景交代地点
- **定点走入走出**：三脚架放在路边，人从画面深处走近再出画，一个人就能拍出「路上的我」
- **主观 POV**：推开门、踩上霜地、手捧热饮，观众替我看
- **手部特写**：拿票、拆包装、冻红的手指
- **延时**：天色变化、云、人流，压缩时间
- **匹配剪辑**：同一个动作换地点、换衣服，交代时间跳跃
- **放下镜头**：结尾把手机放下或盖住镜头，日常感的收尾

## 扩展列

- `A/B-roll`：写类型和机位，例「A-roll · 自拍对镜」「B-roll · 主观」「B-roll · 三脚架定点」「B-roll · 延时」
- `当天时间`：这一镜在当天几点拍的，例「07:05」「09:40（闪前）」；用来检查时间线有没有颠倒

## 画风

默认 `documentary-natural`。

`prompt_prefix` 参考：旅行 vlog 画面，纪实摄影，自然光，真实环境，手机或小相机拍摄的质感，略带手持的不完美构图，柔和颗粒，色彩自然清透

- 拍摄者本人必须建 `refs`，写清发型、外套、帽子、标志性配件；vlog 里当天的衣服就是连续性
- 自拍对镜的 `frame_prompt` 写「自拍视角，人物看向镜头，手臂伸出画外」
- 主观镜头写「第一人称视角，画面下方露出双手」；只拍到手的镜头不挂人物设定

## 声音

- A-roll 收音靠领夹麦或机顶麦，户外风大加防风毛；声音收坏了，B-roll 再好也救不回来
- BGM 在 B-roll 蒙太奇里起，A-roll 说话时压到很低或停
- 不要一首歌循环全片，按段落换 2–4 首，情绪跟着当天走
- 环境声是地点的证据：脚踩霜地、木门吱呀、炉子里柴火噼啪
- 音乐用平台曲库或已授权曲目

## 常见坑

- 流水账：只有时间顺序，没有「今天的问题」
- 开头太慢：起床、刷牙、吃早饭拍了一分钟，还不知道今天要去哪
- A-roll 话痨，没有 B-roll 盖跳切
- 全是风景空镜，没有人，没有反应
- 分镜里写了一个人拍不了的机位（环绕跟拍、远处跟随）
- 房东、路人的正脸没打招呼就用了
- 在禁飞区、景区核心区放无人机
- 时间线颠倒又没交代，观众以为天亮之后又天黑了

## 变体

- **竖屏短 vlog**：1–3 分钟，前 3 秒就放高光结果，一半口述改成字幕，镜长整体减半
- **日常 vlog**：一天的时间线，室内为主，延时和手部特写多，「今天的问题」可以很小（做成一道菜、收拾完一个房间）
- **双人 / 情侣 vlog**：互拍，A-roll 是两个人的对话，两人都要建 `refs`
- **探店 vlog**：和达人口播相邻；有商业合作要在 `open_questions` 写清披露方式，不替商家做功效承诺

## 节奏审核参数

`review.py` 按下面的参数做节奏机检，规则见 `references/director-review.md`。项目选了本卡里的某个子类型（例如快节奏型、慢节奏型）时，在 `project.asl` 里写那个子类型的平均镜长区间。

```pace
asl = 2-8
cps = 4.5
slack = 3
hold = 12
hook = 0
```

asl 平均镜长区间（秒）· cps 台词旁白舒适语速（字/秒）· slack 有台词镜头的余量（秒）· hold 无台词镜头的停留上限（秒）· hook 钩子最晚结束（秒，0 表示不查）
